## Hi, I'm Armel

I'm a backend and platform engineer interested in reliable systems, observability, cloud infrastructure, and the hardware layer behind it all.

I mainly work with **C#/.NET**, **PostgreSQL**, **RabbitMQ**, **Docker**, **Kubernetes**, **Terraform** and **Ansible**. I care about clean architecture, explicit boundaries, readable code, and systems that are easy to understand when something breaks.

At work, I focus on platform engineering and observability topics: OpenTelemetry instrumentation, structured logging, deployment operations, application upgrades, and production diagnostics.

On the side, I build **Seeqr**, a clothing curation app, and **Mustelinet**, a self-hosted private cloud running on custom 3-node hardware with OpenStack, Kubernetes, 10/25G networking, 3D-printed parts and custom watercooling.

Before software engineering, I worked in journalism and communication, which still shapes how I write, document and explain technical systems.

You can reach me at **armeldemarsac@gmail.com**.
